01 / WHY PI DESKTOP

从 agent
到工作流。

pi 负责理解任务、调用模型和执行工具。Pi Desktop 负责把这些动作组织起来：知道在哪个项目里做、哪些操作需要批准、结果如何回到你手上。

这就是桌面端增加的部分。

03 / WORK MODES

同一个 agent，
两种工作场景。

Code 面向软件项目，Work 面向文件和知识任务。两者共享模型、会话和 pi 的配置；等待你处理的事项都回到同一个入口。

⌘

Code：从项目到 PR

每个会话使用独立 worktree，右侧查看 Diff、终端和预览，底部跟踪 PR 与 CI。

☷

Work：从任务到文件

在指定文件夹或临时工作区里整理资料、写文档、生成简报，移动和删除操作会先请求确认。

◷
